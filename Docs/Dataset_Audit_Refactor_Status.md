Основная компоновка вкладки остаётся в `ui_tabs/dataset_analysis_ui.py`.

## Исправления поведения

- OBB XYWHR читаются с реальными шириной/высотой: непрямоугольные снимки
  больше не искажают поворот и площадь.
- Объект маски — отдельная 8-связная компонента положительного pixel ID.
  Площадь считается по пикселям, включая одиночные; фон `0` исключён.
  Таблица, фильтры, тепловая карта и аудит читают одинаковые объекты.
- Валидный пустой TXT отличается от отсутствующего или повреждённого файла.
  Исключение классов не превращает непустую разметку в отрицательный пример.
- Пустой результат фильтрации остаётся пустым для последующих проверок;
  нет неявного возврата ко всему набору. Проверяются перепутанные границы.
  ID классов в дисбалансе сохраняются при наличии нулевых частот.
- Яркость использует общий I/O с Unicode и исходной глубиной; изменение файла
  обновляет кеш. Предпросмотры также используют общий I/O.
- pHash-группы учитывают транзитивное сходство; один путь/алиас не считается
  копией самого себя. Группа кандидатов требует ручной проверки.
- Split берётся из YAML, включая списки отдельных файлов; пересечение одного
  исходника между split обнаруживается без второй физической копии.
  Резервное определение сравнивает точные имена каталогов, не подстроки.
- Аудит сопоставляет GT и предсказания по классу и IoU один к одному,
  учитывает FN/FP и корректные отрицательные снимки. Он сравнивает охватывающие
  прямоугольники; это эвристика отбора, не полноценная метрика OBB/segment.
  Соответствие классов весов и датасета необходимо проверить пользователю.
- PCA работает для одного снимка и одного признака; UMAP вызывается только
  при достаточном числе снимков. Ошибка записи отчёта сохраняет прежний файл.
- При смене данных очищаются устаревшие результаты, прежние задачи отменяются,
  их поздние сигналы игнорируются. Повторный вход через processEvents заблокирован.
  Отмена проверки не выдаётся за успешное завершение или отсутствие утечек.

## Экспорт и остановка

Выходная папка должна быть отдельной и пустой. Имена файлов проверяются на
коллизии до копирования. Данные готовятся во временной соседней папке;
ошибка или отмена удаляет подготовленный результат. Исходники не изменяются.
Непустой существующий датасет не перезаписывается.

TXT получают имя соответствующего изображения и плотные ID выбранных классов.
Флаг исключения классов из файлов управляет именно содержимым разметки;
при выключенном флаге сохраняются все классы отобранных снимков.
PNG-маски остаются PNG: новые pixel IDs начинаются с `1`, фон — `0`.
`data.yaml` включает пути масок и `class_names` с фоном для повторной загрузки U-Net.

Исходные split сохраняются; снимки с неизвестным split попадают в train.
Автоматическое разделение train/val не выполняется, пустые val/test допустимы
для экспорта. Перед обучением подготовьте непустой validation split.
Снимок, объявленный сразу в нескольких split, блокирует экспорт.

Закрытие окна запрашивает кооперативную остановку и прекращает обновление GUI.
Текущий вызов нативного backend нельзя принудительно прервать: он может
завершиться позднее; Python при завершении процесса ожидает исполнитель задач.
Во время синхронного сканирования закрытие откладывается до выхода из операции.

он воспроизведён отдельно на исходном 8b0a526 и исправлен в `ed6e604`.

яркость, дубликаты/split, тепловую карту, TXT/PNG-экспорт и отказ без частичных

к полному набору, отмену, устаревшие ответы и закрытие отдельного/встроенного окна.
Модель аудита заменяется управляемым backend; CLIP использует управляемую
модель и реальный CPU Torch без загрузки весов.

в отдельных процессах — без ошибок. Проверены отсутствие старых импортов
и строковых экспортов, Ruff (неопределённые имена/wildcard и неиспользуемые
импорты новых модулей), компиляция и git diff --check.
Полный прогон: **102 теста успешно**, включая **17 проверок анализа датасета**,
Qt offscreen, все 16 вкладок вместе, автономные точки входа и workers.
Команда: `NEURO_RUN_GUI_TESTS=1 python -m unittest discover -s tests -v`.
