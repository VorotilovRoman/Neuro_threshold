# Переработка анализа датасета и предупреждений о дублирующей разметке

Исходная точка: work `408117b`, 21 ноября 2026.

## Первичные данные

- Воспроизведено аварийное завершение процесса при **нажатии** кнопки качества:
  `serialized_scan` принимает `*args`; Qt передаёт clicked(bool), а исходный
  метод принимает только self. TypeError выходит из Qt-slot и завершает процесс.
  Старые тесты вызывали метод напрямую и этот путь не проверяли.
- Анализ: около 2700 строк контроллера и 1000 строк UI. Качество, MD5/pHash,
  фильтрация и heatmap выполняются синхронно с processEvents. Численная база уже
  находится в `utils_new/dataset_audit`; создавать вторую analytics_dataset
  с теми же загрузчиками/геометрией нецелесообразно.
- Viewer считает пересечение/площадь меньшего с фиксированным 0.70; editor
  проверяет лишь валидность аннотаций. Согласованного индикатора для всех снимков
  и параметров проверки нет. Dataset Preparation использует общий DatasetLoaderMixin
  и отдельный просмотр пары, поэтому проверка должна охватить и этот путь.
- Прямые потребители старой utils: demo_ensemble_methods, yolo_test_aeb,
  yolo_find_img. Осталось два файла utils; также есть ленивые записи реестра.
