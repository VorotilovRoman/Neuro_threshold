# Демонстрация ансамблей: переход на новый просмотрщик

[Документация](README.md) · [Архитектура](Architecture.md) · [Удаление старых утилит](Utils_Removal_Audit.md)

Все четыре поля вкладки — исходник/истинная разметка, YOLO, пресет и ансамбль —
используют `ui.annotation_review_view.DatasetReviewGraphicsView` на базе
`ui.image_view.SmartGraphicsViewNew`. Рисование и редактирование геометрии
мышью отключены; доступны выделение, панорамирование, zoom и сброс масштаба.

## Что изменено

- Общий `_show_image_in_view` передаёт рабочие размеры и нормализованные
  аннотации отдельно от QPixmap. Уменьшение pixmap для отображения не меняет
  координаты и пропорции рамок.
- Рамки/подписи рисует Qt поверх исходных пикселей. Preset сохраняет прежнюю
  маску и белый фон, но рамки больше не впечатываются OpenCV в изображение.
- YOLO worker отдаёт чистое изображение и прежние строки координат/уверенностей;
  `result.plot()` для отображения больше не вызывается. Имена классов передаются
  отдельным сигналом в GUI. Параметры инференса и численные детекции не менялись.
- Панель YOLO показывает имена классов на рамках, confidence остаётся в текстовых
  координатах. Ансамбль и ground truth используют свои классы/координаты.
- Сохранение без разметки записывает базовые пиксели; сохранение текущего вида
  использует общий Qt-просмотрщик. Имена файлов учитывают стадию и исходный кадр.
- Смена кадра очищает предыдущие результаты до нового расчёта. Clear удаляет
  пиксели, векторную геометрию и текст всех четырёх полей; таймер пресета останавливается.

## Проверка удаления старого класса

До удаления `utils/smart_view.py` проверены прямые/локальные импорты, конструкции
`from utils import ...`, строковые имена динамических модулей и экспорт
`SmartGraphicsView` из `import_libs_internal.py`. Единственный рабочий UI-потребитель
переведён на новый класс; старый строковый экспорт удалён. Других потребителей нет.
Затем удалён старый файл; `test_removed_utilities_have_no_code_or_registry_consumers`
теперь запрещает возвращать обращения к `utils.smart_view`.

Исторические упоминания и ссылки на старые коммиты в документации не являются
зависимостями программы. Новые графические классы не импортируют старый файл.

## Проверки

Три новые регрессии в `tests/test_ensemble_view.py` проверяют:

1. YOLO worker со stub-моделью передаёт неизменённые пиксели, имена классов и
   точные детекции без вызова plot и без скачивания весов.
2. Четыре панели внутри main, векторные объекты, confidence, сохранение чистых
   пикселей, ограниченный QPixmap, смену размера кадра и очистку.
3. Автономное окно: колесо мыши, средняя кнопка, настоящие drag через QWindow,
   общий сброс масштаба и неизменность координат аннотаций.

Полная suite с GUI: **56 тестов успешно** на Linux CPU / Qt offscreen.
Независимые импорты всех **135 прикладных модулей** проходят; workers обучения
не загружают Qt.
Ruff F821/F822/F823/F403/F405, компиляция и проверка локальных ссылок Docs проходят.

Реальные модели YOLO и Windows/CUDA в этом проходе не запускались. Автоподбор
методов сегментации, его исходники и настройки не изменялись.
