# Перенос последних трёх вкладок с utils

Исходная точка: work 6c6e680, 21 ноября 2026.

## Первичные данные и решения

- Чтение, нормализация, размер, lazy cache уже есть в dataset_files_new;
  Qt-преобразование — ui/image_conversion; выбор/пакетная загрузка —
  ui/segmentation/image_input. Использовать эти реализации.
- Ансамбль теряет классы (выход всегда class=0), NMS игнорирует веса,
  оценка пресетов игнорируется; вложенность определяется слишком широко по центру.
  Вычисления объединения — в существующий annotations/boxes.py,
  обработка порогового пресета — в threshold_processing.py.
- Старые выделители объектов Qt-зависимы. Использовать общую геометрию
  segmentation/postprocessing и annotation_processing, как на пяти вкладках.
- QThread заменяется/освобождается после короткого wait, даже если модель ещё
  работает. Нужны безопасные фоновые задачи, отмена и защита поздних сигналов,
  включая закрытие через main. Расширить существующий ui/segmentation/jobs.
- Поиск предварительно уменьшает снимок до 640, затем считает отступ в пикселях
  уменьшенного кадра. Читать исходный размер; imgsz остаётся настройкой модели.
  Ошибка загрузки модели должна завершать задачу и восстанавливать UI.
- AE/VAE выполняется в GUI, часть проверки каналов вне try; неудачное чтение
  следующего снимка оставляет старое изображение/карту ошибок. Нужны фоновые
  операции и явное очищение устаревшего результата, общий writer для Unicode.
- Моделям AE/VAE подходящего владельца в utils_new нет. Перенести существующий
  utils_aeb/yolo_aeb_utils.py в segmentation/autoencoder.py (единственный новый
  файл утилиты: перенос уникальных архитектур, не копия общего I/O). Импортировать
  Torch/архитектуры только при модельной операции. Убрать ненужные реэкспорты.
