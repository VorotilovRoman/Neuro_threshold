# Документация Threshold‑Researcher

Документация актуализирована 11 ноября 2026 года для ветки `work` после миграции импортов и повторной проверки OpenCV.

- [Руководство пользователя](User_Guide.md): установка, 16 вкладок, форматы, сохранение результатов и ограничения.
- [Решение по OpenCV](OpenCV_Decision.md): сравнение headless/desktop, требования пакетов, ограничения и условия пересмотра.
- [Windows: c10.dll / WinError 1114](Windows_Torch_DLL.md): исправление повторной попытки и диагностика нативного загрузчика.
- [Зависимости и установка](Dependencies.md): закреплённые версии, дополнительные библиотеки, внешние ресурсы и проверка среды.
- [Итоговый аудит](Import_Audit.md): проверки всех Python-файлов, запусков и зависимостей.
- [План миграции импортов](Import_Architecture_Plan.md): этапы, критерии и результаты изменения архитектуры.
- [Аудит пяти вкладок сегментации](Segmentation_Tabs_Audit.md): фактические зависимости, общие части, подтверждённые дефекты и пробы.
- [Результат общего рефакторинга](Segmentation_Refactor_Status.md): выполненные переносы, совместимость, проверки и отложенный автоподбор.
- [План миграции сегментации](Segmentation_Migration_Plan.md): новые/существующие компоненты, этапы, совместимость и критерии приёмки.
- [Карта архитектуры](Architecture.md): путь от запуска до утилит, реальные связи вкладок, ветки старого и нового кода.
- [Дублирование и качество связей](Duplication.md): подтверждённые копии, перекрытие импортов, корректное разделение ответственности и приоритеты рефакторинга.
- [Справочник модулей](Module_Reference.md): прямые импорты всех Python-файлов, обратные связи и полный перечень функций/методов утилит. Это справочник для поиска, а не руководство по интерфейсу.

Справочник и приложение с точными копиями воспроизводятся командой `python Docs/generate_reference.py`. Скрипт читает AST, не импортирует приложение и не требует сторонних библиотек. После изменения кода обновляйте также смысловые выводы в остальных документах.

Скриншоты `Screenshot_1.png`–`Screenshot_3.png` сохранены как прежние иллюстрации; они не подтверждают текущую компоновку интерфейса. `test_image.png` и `test_image.txt` — небольшой пример для загрузки и проверки разметки. Ранее разрозненные инструкции по вкладкам объединены в руководство, чтобы не поддерживать несколько противоречащих описаний.
