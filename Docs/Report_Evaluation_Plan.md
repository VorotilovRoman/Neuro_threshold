# Проверка автоподбора и выбора методов по эталонному датасету

Исходная точка: `work 4f03977`. Цель — выбрать воспроизводимые полные пресеты
пороговых/градиентных методов по фактическому качеству разметки одного и того же
ручного эталона. Регрессия по собственным обучающим строкам не является оценкой.

- [x] Проверить паритет автоподбора с вкладками, сохранение геометрии, размеров,
  ошибок, завершённости и условий обработки в отчётах.
- [x] Добавить отдельную строгую загрузку эталона (YOLO YAML/папка), сопоставление
  изображений с отчётами, диагностику пропусков, неоднозначных имён и размеров.
- [x] Добавить оценку BBox/OBB/Segment по геометрии и однозначное сопоставление
  объектов. Показать режим учёта классов; классические методы не узнают семантику.
- [x] Считать Precision/Recall/F1, TP/FP/FN, качество локализации, средний F1 по
  IoU и показатели отрицательных снимков на фиксированном наборе изображений.
  Ошибки и отсутствующие вычисления не должны улучшать рейтинг.
- [x] Ранжировать точный пресет и условия обработки по измеренным метрикам;
  отдельно показать полноту покрытия, лучшие методы и лучшие параметры.
  Исключить влияние разрушительных фильтров/усреднения лучших снимков на вывод.
- [x] Обновить основной сценарий UI: эталон → оба вида отчётов → оценка →
  понятный результат, детализация ошибок, экспорт оценки и перенос пресетов.
- [x] Добавить сквозные и регрессионные проверки; обновить Docs/README,
  проверить импорты, выполнить полную suite и опубликовать коммиты в work.

Ограничения: подбор оценивает загруженный эталон, не доказывает качество на
невиданных данных; mAP нельзя называть средний F1. Геометрию OBB/Segment нельзя
неявно заменять охватывающими BBox. Выбор по неполному покрытию требует явного
указания, такой пресет не объявляется победителем по всему датасету.

Приёмка завершена: 115 тестов, 168 независимых импортов, dependency_health
с реальной загрузкой библиотек, статические проверки и ссылки Docs — успешно.
Код: `3dc8dc0`, `03e0d33`; параметры в выводе восстанавливаются из полного
пресета, условия resize сохраняются и применяются соответствующей вкладкой.
