# План унификации пяти вкладок сегментации

[Документация](README.md) · [Предыдущий пиксельный этап](Pixel_Morphology_Plan.md)

Исходная точка: work, `56b7737`. План принят к реализации по заданию пользователя.
Автоподбор пороговых/градиентных методов и его настройки остаются последним этапом:
исходники и уникальные методы поиска не меняются, кнопки пока отключены.
Совместимость старых настроек/импортов не требуется.

## Контракты

- Четыре режима: «Нет», «BBox», «OBB», «Segment». В данных используются
  `none/detect/obb/segment`: `detect` — это BBox того же AnnotationKind,
  который используется редактором датасета. Нового формата геометрии не вводим.
- BBox — связные компоненты и осевые прямоугольники; OBB — ориентированные
  прямоугольники; Segment — контуры. Один extractor и одинаковое применение hull
  только к OBB/Segment. Размеры и нормализованные tuples согласованы с редактором.
- Список объектов одинаков: галочки задают экспорт/видимость, выбранная строка —
  фокус объекта. Фокус и галочки независимы, индекс сопоставляется с полным списком.
- Состояния: нет изображения, маска не вычислена, вычисление, готово (включая
  валидную нулевую маску), ошибка. Ошибка не подменяется пустой успешной маской.
- Без маски/при ошибке показываем исходное изображение, пустые стадии маски и
  отсутствие объектов; с валидной пустой маской — белый результат без объектов.
- Глобальные настройки меняют только Qt-отрисовку. Маски, набор объектов,
  галочки и координаты не пересчитываются и не сбрасываются.
- Сохраняются индивидуальные порядки стадий, градиентные fill/min-area,
  интерактивные ROI/FG/BG, ML metadata/features и DL preprocessing/device.
  Рабочие пределы: 1024 у threshold/gradient/interactive, 640 у ML/DL.
