Исходная точка: work fb6fadb. 22 ноября 2026.

## Первичные данные

Проверены все 16 записей ALL_TABS, их UI, обработчики и общие адаптеры.
Сохраняются разные назначения источников, а одинаковые операции получают один UI.

| Вкладки | Фактический вход до изменений |
| --- | --- |
| Пороговые, градиентные, интерактивные | Файлы снимков/папка, метки рядом; штрихи/ROI — пользовательский ввод |
| Традиционный ML | Снимки/папка, текущие загруженные снимки с соседними YOLO TXT либо псевдометками Otsu, модель |
| Deep Learning | Снимки/папка, веса выбранной модели; обучение — отдельная вкладка |
| Анализ отчётов | Ручной эталон YOLO YAML/папка TXT, готовые отчёты файлами/рекурсивной папкой |
| Добавить аннотации | Снимки/папка, TXT, YOLO YAML, COCO, YAML с масками с преобразованием в полигоны |
| Просмотр аннотаций | То же + отдельная папка индексных масок для наложения |
| Подготовка/анализ датасета | Папка снимков, TXT/маски/без меток, YOLO YAML, COCO с заменой/добавлением, YAML с масками |
| SAHI | Папка снимков/TXT, YOLO YAML, COCO; индексные маски не поддерживаются |
| Обучение | YOLO: корневая папка/YOLO YAML; U-Net/DeepLab: папка/масочный YAML; дополнительные веса/пресеты. SAM/SegFormer — заготовки |
| Демонстрация | Снимки/папка, пороговые пресеты, веса YOLO |
| Сортировка YOLO | Корневая папка рекурсивного поиска + веса YOLO |
| YOLO + AE/VAE | Снимки/папка, веса YOLO и checkpoint AE/VAE |
| Настройки | Параметры приложения; входного датасета нет |

Проблемы: разные подписи и порядок кнопок; отдельные копии панелей подготовки,
анализа и SAHI; источник смешан с экспортом; длинные ряды обрезают интерфейс;
одинаковые QFileDialog размножены, фильтры отличаются (YOLO inference выбирает
только PT, хотя поддерживает ONNX/engine). Подпись Segment о чётном количестве
токенов неверна: чётно количество координат, вся строка имеет нечётное число токенов.

Численные службы каталогов уже общие: dataset_catalog_new, dataset_yaml_new,
dataset_unet_new, dataset_coco_new, dataset_files_new и dataset_pair_tools_new.
Не создавать вторую систему парсинга датасетов.
