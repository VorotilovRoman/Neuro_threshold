# Градиентные методы

[README](../README.md)

Поиск границ: Sobel, Scharr, Laplacian, Canny, Prewitt, Roberts и Kirsch.
Вход — файлы снимков или папка.

1. Выберите метод, его ядро/масштаб/пороги и порог бинаризации градиента.
2. Настройте морфологию, фильтр площади и заполнение контуров.
3. Выберите BBox/OBB/Segment, проверьте объекты и сохраните результат.

Автоподбор использует те же кнопки и диапазоны, что пороговая вкладка;
отчёты `*_gradient_report.txt` сохраняются рядом со снимками. Сравните их с
ручным эталоном в [анализе отчётов](reports.md).
Разорванные границы не гарантируют заполненную маску; метод не обучает веса.
Алгоритмы: `utils_new/segmentation/backends/gradient.py`.
