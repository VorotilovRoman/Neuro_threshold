# Пороговые методы

[README](../README.md)

Бинаризация снимков и папок: Simple, Otsu, Triangle, Adaptive Mean/Gauss,
Niblack, Sauvola, ISODATA, Background Symmetry и Row Adaptive.

1. Загрузите снимки, выберите метод и его параметры.
2. Настройте инверсию, морфологию и режим BBox/OBB/Segment.
3. Проверьте объекты в таблице; сохраните разметку или пресет.

Автоподбор: задайте диапазоны, выберите текущий кадр/все загруженные и запустите
поиск. Он читает снимки последовательно, сохраняет `*_full_report.txt` рядом с
ними; остановка оставляет отдельный partial-файл. Для выбора лучшего рецепта
по ручным TXT откройте [анализ отчётов](reports.md).
Пороговые методы не обучают веса. Размеры ядер относятся к рабочему разрешению.
